# Maintainers

This project is maintained by a single maintainer.

## Maintainer

- **Eddie Wade** (GitHub: [narko4u](https://github.com/narko4u)) - Empire Labs Pty Ltd

## Collaboration policy

- All changes to the default branch land via pull request. Direct pushes to the default branch are disabled by branch protection.
- Every pull request must pass the required CI checks before merge.
- The maintainer reviews and merges all pull requests.

## Non-author approval

This is a single-maintainer project: there is currently no non-author human reviewer, so a non-author approval requirement cannot be satisfied. If additional maintainers or reviewers join, the following policy applies: collaborators are reviewed before being granted escalated permissions, and non-author approval is required for all merges.

## Becoming a maintainer

At this stage the project is not accepting new maintainers. Anyone interested in long-term stewardship can open an issue to discuss it.
